# Graph Datasets

K3Node provides multi-backend graph datasets compatible with `k3_node.data.Data` and `k3_node.data.HeteroData`. All datasets are built on top of `k3_node.data.InMemoryDataset` or `k3_node.data.Dataset`, outputting native backend-agnostic tensors that seamlessly run across **PyTorch**, **TensorFlow**, and **JAX**.
