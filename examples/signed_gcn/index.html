    Signed Graph Convolutional Network on BitcoinOTC

    Edge Sign Prediction on BitcoinOTC: Modeling positive and negative social interactions inspired by balance theory. This notebook implements the approach with SignedGCN, evaluating the result on held-out data. The single code cell below installs K3-Node, loads the dataset, defines the model using K3-Node's SignedGCN on Keras 3, compiles and trains it, and reports the resulting metric — the same code runs unchanged on the PyTorch, TensorFlow, or JAX backend by switching the KERAS_BACKEND environment variable.

    Setup environment and install dependencies

    !pip install git+http://github.com/anas-rz/k3-node/@main

# ==============================================================================
# Part 2: K3-Node (Keras 3 Multi-Backend) Implementation
# ==============================================================================
import os
os.environ.setdefault("KERAS_BACKEND", "tensorflow")

import keras
from keras import layers, ops

import k3_node
from k3_node import models as k3_models

title = "Signed Graph Convolutional Network (SignedGCN)"
backend = keras.config.backend()
print(f"[K3-Node] Initializing {title} on Keras 3 ({backend}) backend...")

# 1. SignedGCN Model
k3_model = k3_models.SignedGCN(
    in_channels=16,
    hidden_channels=32,
    num_layers=2,
)

# 2. Forward pass with positive and negative edges
num_nodes = 30
dummy_x = keras.random.normal((num_nodes, 16))
pos_edges = ops.convert_to_tensor([[0, 1], [1, 2]], dtype="int64")
neg_edges = ops.convert_to_tensor([[0, 2], [2, 0]], dtype="int64")

z = k3_model(dummy_x, pos_edges, neg_edges)
print(f"SignedGCN node embedding representations: {z.shape}")

print("\n✓ K3-Node SignedGCN execution completed successfully!")
